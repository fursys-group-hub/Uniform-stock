# LETUS 시공팀 유니폼 재고관리 플랫폼 — 소개

## 1. 한 줄 요약
> **본사 담당자는 유니폼 재고를 "관리"하고, 시공팀은 재고를 실시간으로 "확인·요청"하는 — 하나의 데이터로 연결된 재고관리 플랫폼.**

---

## 2. 왜 만들었나 (배경)
- 기존엔 시공팀이 "○○ 재고 있어요?" 물을 때마다 담당자가 **수기로 확인·회신** → 반복·비효율.
- 재고 데이터가 **개인 브라우저에만 저장**돼 있어 유실 위험이 컸음.
- 그래서 → **중앙 DB에 영구 저장** + **시공팀이 직접 실시간 확인** + **요청까지 한 번에**.

---

## 3. 핵심 구성 — 두 개의 링크, 하나의 데이터

| | 🗂 관리자 플랫폼 | 📋 시공팀 공개 대시보드 |
|---|---|---|
| 주소 | `…/` | `…/request` |
| 대상 | 본사 유니폼 담당자 | 시공팀 요청자 |
| 접근 | 관리자 **로그인** | 진입 비밀번호(`1593`) |
| 하는 일 | 등록·수정·실사·단가·분석 | **조회 + 요청** |

> 두 화면은 **같은 백엔드·같은 DB**를 봅니다.
> → 관리자가 입고를 등록하면 **시공팀 화면에 실시간으로 반영**됩니다. (독립된 두 링크, 연결된 하나의 데이터)

---

## 4. 주요 기능

### 🗂 관리자 플랫폼 (로그인)
- **재고 현황**: 분류별 그룹핑 · 상태(여유/부족/품절) · **재발주 필요** 지표 · **엑셀(CSV) 내보내기**
- **수불 등록/이력**: 입고·분출·반납·재고조정 (누가 했는지 기록)
- **실사 등록/이력**: 전산수량 vs 실제수량 차이 자동 계산·조정
- **단가 관리 / 청구 조회**: 분출 기준 청구금액을 담당자별로 집계
- **분석 대시보드**: 월별 입출고 추이 · 재고회전율 · 수요예측 · 안전재고 재발주 알림
- **활동 로그**: 누가·언제·무엇을 했는지 전체 기록

### 📋 시공팀 공개 대시보드 (로그인 없이)
- **실시간 재고 조회**: 분류 → 품목 → 사이즈 연계 필터 · **초성 검색**(ㄷㄱ→동계)
- **상태 색 표시**: 🟢 여유 / 🟠 부족 / 🔴 품절
- **유니폼 요청**: 장바구니에 담기 → 요청자·권역·**센터(드롭다운)** 입력 → **요청 보내기**
  → 본사 담당자 **슬랙 DM으로 자동 알림** (요청일시·품목 자동 정리)
- **가격 확인**: 비밀번호 입력 시 품목별 단가 표시

---

## 5. 기술 구조 (쉽게)

```
[브라우저]  →  [중간 서버(백엔드)]  →  [회사 전용 DB]
 화면            안전 처리·보관            데이터 원본
```
- **백엔드(Node.js)**: 로그인·데이터·요청을 처리. **DB 비밀번호는 서버 안에만** 두어 외부에 노출되지 않음.
- **회사 전용 DB**: 모든 재고·수불·이력의 **단일 진실 원본**(다른 기기·브라우저에서도 같은 데이터).
- **슬랙 연동**: 시공팀 요청을 담당자 개인 DM으로 전달(봇 없이 워크플로 웹훅).

---

## 6. 접근·보안 정리

| 구분 | 수단 | 목적 |
|---|---|---|
| 관리자 로그인 | 관리자명 + 비밀번호 | 등록·수정은 담당자만 (쓰기 권한) |
| 공개 대시보드 진입 | 비밀번호 `1593` | 장난성 접속 방지 |
| 가격 확인 | 별도 비밀번호 | 단가 정보 보호 |
| 서버 비밀값 | DB접속·비번·슬랙 웹훅은 **서버 설정에만** | 코드·GitHub에 노출 없음 |
