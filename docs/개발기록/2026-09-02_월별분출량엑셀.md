## 🔍 깊게 보기 — 무엇을 뽑아주나 (비전공자용)

### 1. 한 줄 요약
버튼 하나 누르면, **행=품목·사이즈 / 열=각 월 / 값=그 달 나간 수량** 인 엑셀 파일이 받아져요.

### 2. 어떤 모습
```
분류      품목    사이즈  2025-10 … 2026-08   합계
유니폼상의 조끼    105        20   …    30      ...
유니폼상의 조끼    110         5   …    22      ...
```
→ 엑셀에서 피벗·정렬·그래프로 자유롭게 분석.

### 3. "말일 기준"으로 바꾼 이유 (❌ vs ✅)
❌ 처음엔 **이번 달(진행 중)** 까지 포함 → 마지막 열이 "오늘까지만" 집계돼 **어중간**하게 보임(“왜 26일 기준이냐” 오해).
✅ **완결된 달만**(진행 중인 이번 달 제외, 지난달까지) + **데이터 있는 전체 월** 을 한 번에.

### 4. 핵심만
- 값 = **순소비(분출−되돌림)**, 한글 안 깨짐(BOM)
- 마지막 열 = **지난달** 까지로 깔끔하게 끊김

## 🤔 고민 과정

- **"왜 26일 기준이냐"** 는 질문의 진짜 원인은 **진행 중인 이번 달** 이 마지막 열이라 부분집계처럼 보인 것. → "달력상 완결된 달만" 으로 정리하니 오해가 사라졌다.
- **한 번에 다운** — 특정 12개월만이 아니라, **데이터가 있는 첫 달~지난달 전체** 를 연속으로 담아 "한 파일로 끝"이 되게 했다(최대 36개월).
