## 🔍 깊게 보기 — "결품·부족을 어떻게 한눈에?" (비전공자용)

### 1. 한 줄 요약
현재고가 **안전재고 이하**인 품목을, **품목별로 묶어서** "품절 N · 부족 N · 부족분 O벌"로 보여줘요.

### 2. 왜 이렇게 했나 (❌ vs ✅)
❌ **사이즈별로 한 줄씩** — 15줄이 주르륵 나와서 눈에 안 들어옴.
✅ **품목별로 묶기** — 조끼·하계셔츠처럼 4~5줄로 압축 → "어떤 품목을 발주해야 하나"가 즉시 보임.

### 3. 흐름 (그림)
```
현재고(실시간) ──┐
                 ├─▶ 상태 판정: 현재고 ≤ 안전재고 → 부족/품절
수요(과거+분출) ─┘        │
                          ▼
              품목별 묶음: 🔴 조끼  품절 2·부족 1  (90·100 품절, 105 부족)  부족분 40벌
                          + ★수요상위 태그(인기 사이즈가 비었으면 특히 위험)
```

### 4. 핵심만
- 상태는 **현재고 vs 안전재고**로 판정, **품목별로 묶어** 가독성↑
- 인기 사이즈가 빈 품목엔 **★수요상위** → 발주 우선순위

## 🤔 고민 과정

- **"현재고는 있는데 수요는 어떻게 알지?"** — 재고 숫자만으론 "뭘 먼저 준비할지"를 못 정한다. 그래서 **수요(과거 이력 + 실시간 분출)** 를 얹어 "인기 사이즈인데 비었다"를 잡게 했다.
- **순소비 개념** — 단순 분출이 아니라, 잘못 분출 후 되돌린 건 빼야 정확하다는 판단(이후 며칠간 더 정교화).
- **청구를 월별로도** — 권역별 총계만으론 "이번 달 얼마 나갔나"를 못 본다. 권역 × 월 교차표로 시점을 추가.
