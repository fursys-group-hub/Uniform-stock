# 시공팀 유니폼 재고관리 플랫폼 — 도입 효과 보고

> **목적:** 기존 수기·문의 기반 재고관리를, 실시간 연동 플랫폼으로 전환했을 때의 개선점과 효용 정리
> **구성:** 관리자 플랫폼(본사 담당자) + 시공팀 공개 대시보드(현장 요청자) — 하나의 데이터로 연동

---

## 1. 한눈에 보기 (Before → After)

| 구분 | 기존 방식 (Before) | 개선 후 (After) |
|---|---|---|
| **재고 확인** | 시공팀이 담당자에게 매번 문의 → 담당자가 확인·회신 | 시공팀이 **직접 실시간 조회** (문의 불필요) |
| **데이터 보관** | 개인 PC·엑셀·브라우저에 저장 (유실 위험) | **중앙 DB에 영구 저장** (어디서나 같은 데이터) |
| **유니폼 요청** | 전화·메신저·구두 → 누락·오류 | 화면에서 담아 전송 → **담당자 슬랙 자동 알림 + 기록** |
| **수불·이력** | 수기 기록 (추적 어려움) | 자동 기록 + **활동 로그**(누가·언제·무엇을) |
| **부족·품절 인지** | 눈으로 확인 → 뒤늦게 발견 | **상태색·재발주 필요 지표**로 즉시 인지 |
| **발주 판단** | 감·경험 | **회전율·수요예측·안전재고** 데이터 기반 |
| **보고·정산** | 수작업 취합 | **엑셀 내보내기**, 담당자별 청구 자동 집계 |

---

## 2. 기존 방식의 문제점

1. **반복 문의·응대 부담** — 시공팀이 "○○ 재고 있나요?"를 물을 때마다 담당자가 확인·회신 → 양쪽 모두 시간 소모, 업무 중단.
2. **데이터 유실 위험** — 재고 정보가 담당자 개인 PC/브라우저에만 존재 → 기기 변경·캐시 삭제·담당자 이탈 시 소실.
3. **요청 누락·오류** — 구두/메신저 요청은 기록이 남지 않아 빠지거나 잘못 전달.
4. **추적 불가** — 누가 언제 무엇을 입·출고했는지 확인 어려움.
5. **재고 최적화 한계** — 부족·품절을 늦게 인지, 발주가 경험 의존.

---

## 3. 핵심 개선점

### ① 실시간 셀프 조회 — "묻지 않아도 되는" 재고 확인
- 시공팀이 **공개 대시보드**에서 직접 실시간 재고를 확인.
- 담당자 확인·회신 왕복이 사라짐. (분류→품목→사이즈 필터, 초성 검색 지원)

### ② 중앙 데이터베이스 — 유실 없는 단일 원본
- 모든 재고·수불·이력이 **중앙 DB에 영구 저장**.
- 어느 기기·누가 보더라도 동일한 최신 데이터. 담당자 이탈에도 안전.

### ③ 요청 자동화 — 담기 → 전송 → 슬랙 알림
- 시공팀이 필요한 유니폼을 담아 요청하면 **본사 담당자 슬랙으로 자동 알림**(요청일시·품목·센터 자동 정리).
- 요청이 **기록으로 남아** 누락·오류 감소.

### ④ 관리·분석 강화
- **상태 표시**(여유/부족/품절)와 **재발주 필요** 지표로 결품 예방.
- **분석 대시보드**: 월별 입출고·재고회전율·수요예측·안전재고 알림.
- **활동 로그**로 전 작업 추적, **엑셀 내보내기**로 보고·발주 편의.

### ⑤ 권한 분리로 안전
- 등록·수정은 **관리자 로그인** 후에만 → 데이터 무결성.
- 시공팀 화면은 **조회·요청 전용** → 실수 방지.

## 4. 기대 효용

| 대상 | 효용 |
|---|---|
| **본사 담당자** | 반복 문의 응대 감소 · 요청 자동 접수·기록 · 발주/정산 자동화로 업무 부담 ↓ |
| **시공팀(현장)** | 실시간 즉시 확인(대기 없음) · 간편 요청 · 요청 진행 투명화 |
| **조직 전체** | 데이터 유실 리스크 제거 · 재고 정확도·신뢰도 ↑ · 결품/과잉 감소 · 이력 추적으로 관리 투명성 ↑ |

> 정량 효과(문의 건수·응대 시간 절감 등)는 운영 후 **활동 로그·요청 기록**으로 실측 가능합니다.

## 5. 현황 및 향후 계획

- **현재:** 기능 개발 완료, 사내 서버 배포·회사 DB 연동 검증 완료.
- **구성:** 관리자 플랫폼 + 시공팀 공개 대시보드(두 링크, 데이터 연동).
- **향후:** 외부(현장 권역장)에서도 접근 가능하도록 **공개 접근 방식 확정**(사내 정책 협의 중).
